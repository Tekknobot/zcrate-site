Your first sample idea

Index a folder, find a passage and make a short sequence you can keep.

Start with a collection

SAMPLE-01 is built for exploring large sample collections without spending time dropping each individual track into a DAW. It also works with smaller collections: choose a folder, index the recordings and audition musical passages in one place.

↳
Development build manual

This guide covers the current local 1.1.0 (7) development build. Its synths, drums, mixer and arrangement features may differ from earlier builds. About this edition →

  1. Choose a folder

    Use File → Choose SAMPLE Folder…, or open Index library · batch or all songs in Library and choose Choose folder….

  2. Index a first batch

    Choose Scan next 10 for a manageable start, or Scan all songs for the folder. The app reads FLAC, MP3 and WAV files without changing the originals.

  3. Browse the results

    Use Refresh library when indexing finishes. Select a song, choose a passage Length and click a waveform to audition it once.

Build a loop in Editor

Drag a passage from Library to Editor. Drag its body to move it and its right edge to shorten it. Set Bars to 1, 2, 4 or 8 and add more passages. Use the global Play and Loop controls with Workspace selected.

For a starting point made from one recording, choose New idea. Listen, keep the parts you like and try Vary current for different responses or endings. Learn how the locks work →

Add drums and synths

Open Drums and click steps to program a beat, or try a generated pattern. Open Synths, choose Bass, Lead, Poly or Pad, and draw notes or generate a part. Follow editor samples uses the sample-key estimates as a guide; Manual key lets you choose your own harmony.

Use Mixer to balance the parts. When you want a longer structure, open Arrangement, enter an Idea name and choose Add workspace. Build an arrangement →

Save the work and take it onward

Use File → Save Project to save the editable project. Use File → Export → Editor WAV… for an audio version of the short workspace, or export the longer arrangement from Arrangement.

↳
Keep the audio with the project

A normal .sample01 project stores settings and audio references. Choose a Portable Project ZIP when you need an editable copy with its required audio. Recovery autosave is separate from saving the named project. Projects & recovery →

Index & browse a library

Make a searchable local index while keeping the original recordings untouched.

Choose and index a folder

Use File → Choose SAMPLE Folder… to select the folder containing your recordings. In Library, open Index library · batch or all songs. Scan next 10 processes a batch; Scan all songs continues through the collection. Unchanged files are skipped on later scans.

Cancel scan stops after the current recording. Check Skipped files for items that could not be processed, then use Refresh library to load the indexed results.

InputCurrent support
Audio formatsFLAC, MP3 and WAV.
Recording lengthUp to 20 minutes per source file.
Channels and sample rateUp to 8 channels and 192 kHz.
Original filesRead for analysis and playback; never rewritten by SAMPLE-01.

Use Songs and Library together

Songs lists the indexed recordings. Use Find song or artist to narrow that list, then select a song to show its passages in Library. All songs returns to the whole index. Selecting a song keeps your Length choice and clears the key and source-BPM filters.

The Songs and Library buttons show or hide each sidebar independently. Drag the divider beside Songs to adjust its width. Smaller windows can show the panels over the workspace; hiding a panel gives the editor more room.

Keep the index useful

Use Refresh library to reload existing results; scan again to analyze new or changed recordings. If a source has moved, restore access to its folder before trying to audition it. A saved project that refers to the original library still needs those files.

↳
Indexing and audio preparation share resources

A new pitch, tempo or preview render can wait while the current recording is being indexed. Let that recording finish, or cancel the scan and continue working. Troubleshooting →

Find & audition passages

Narrow the collection by musical length, source tempo and key, then trust your ears.

Choose the passage you need

FilterWhat it controls
Length¼, ½, 1, 2, 4 or 8 bars, or All lengths. The suggestions assume 4/4 time.
BPMThe original estimated tempo, rounded to a whole BPM. This is independent of Playback BPM.
Key sourcePassage estimate analyzes each excerpt. File tag uses the recording’s key metadata.
KeyA specific key, All keys, or the available Uncertain / Untagged category.
Beat gridDetected, Half tempo or Double tempo for the selected song. See Beat-grid interpretation.

Each passage shows its source position, musical length, duration, key information and a miniature waveform. Results are paged, so use the navigation controls to continue through a song or the collection.

Listen before placing

Click a passage waveform to audition it once. Audition sample plays the selection once again; Loop sample repeats it. The global Stop control ends playback. Drag a passage into Editor when you want to use it in a sequence.

A taller miniature waveform is not proof that one passage is louder than another: each cell is normalized for display. Listen or use the mixer meters when comparing levels.

Read estimates as suggestions

Passage detection assumes 4/4 and looks for nearby kick- or snare-like transients. Instrument detection inside a full mix is approximate, and windows without nearby drum evidence may be omitted. Sparse, irregular or changing-tempo recordings can produce fewer useful suggestions.

↳
Key is an estimate

Short passages, drum-heavy audio, tuning drift and relative major/minor relationships can mislead the analysis. Uncertain means there is no clear match, not that the passage is unusable. A file tag is separate metadata, not confirmation of the detected key. Listen before committing to a harmonic match.

Playback, tempo & pitch

Choose what plays and change its timing without rewriting the source audio.

Choose the playback source

The global transport selects Workspace or Arrangement. Workspace plays the short editor with its enabled drum and synth parts. Arrangement plays the longer song timeline. Use Play, Stop and the Loop toggle for the selected source.

Bars sets the short workspace to 1, 2, 4 or 8 bars; it is separate from the full arrangement length. With Workspace Loop off, playback completes its cycle. Arrangement uses its own loop brace. Press Stop again while already stopped to return the arrangement to bar one.

Space toggles playback when focus is outside a field, button or dialog. Local sample and instrument audition controls are useful for checking a sound separately from the full mix.

Separate tempo from pitch

ControlResult
Playback BPMSets the playback tempo from 40 to 240 BPM. Audio is time-stretched to follow it.
Source tempoClears the playback-tempo override.
PitchTransposes sample audio from −12 to +12 semitones while preserving its duration.
Reset pitchReturns the global sample transposition to zero.

Tempo stretching and pitch shifting are independent. A new setting can require audio preparation before it is heard. Large changes can soften transients or reveal processing artifacts, so compare the result at a smaller change when needed. Original recordings stay unchanged.

Correct a half- or double-time interpretation

Select a song, then choose Detected, Half tempo or Double tempo under Beat grid. This changes how the song’s detected timing is interpreted. It does not retune the audio or require a new scan.

↳
Already-placed clips keep their timing

The setting belongs to the song. Existing saved clips retain their captured timing; choose a new passage, replace the clip or make a New idea to use the revised interpretation.

Edit sample sequences

Arrange passages into a short workspace, then refine their timing and balance.

Place and shape clips

Open Editor and drag a passage from Library onto the canvas. Drag the clip body to move it; drag its right edge to trim it. Set the workspace Bars to 1, 2, 4 or 8. Gaps play as silence, so you can leave deliberate space between phrases.

↳
Shortening is reversible

Clips beyond the workspace end are retained. Playback and editor export stop at the current boundary; increase Bars again to reveal the later material. Clear editor clears sample clips, not the drum and synth parts.

Work with one clip or a group

Click to select a clip and Shift-click to select more. Use Copy, Paste, Duplicate and Delete from Edit or their keyboard shortcuts. Copy and paste preserve the relative positions of a selected group. Duplicate places a copy after the selection when there is room.

If an edit would not fit, SAMPLE-01 reports the problem instead of overwriting clips. Undo and Redo cover the editing actions. A clip’s context menu also offers sample export, hook creation and key-matched replacement. Keyboard reference →

Balance passages before building further

Match levels applies a fixed stereo gain adjustment to help passages sit together. It targets an approximate −18 dBFS RMS level, limits upward gain to 12 dB and preserves peak headroom. It is not a compressor and does not raise near-silence.

Use global Pitch for the overall sample transposition and the clip’s transposition controls for individual changes. The Sample mixer channel provides the shared final sample balance. Mixer →

New idea & Random locks

Build a recurring hook from one song, keep useful constraints and vary the response.

Generate a New idea

New idea searches indexed passages from one song and builds an editable hook. It weighs timing, tone, energy and recorded drum activity, repeats a motif and can introduce different responses near the end of a phrase. A completed draw replaces the sample editor and normally auditions once.

Ideas use equal-length chops of ¼, ½, 1 or 2 bars, with 4–32 chops in a sequence. Unlocked ideas generally make 4- or 8-bar workspaces; a compatible locked Editor length can constrain that total. Recent results are avoided, and an unsuccessful draw leaves the editor unchanged.

↳
A musical starting point

This is a constructed arrangement of recorded passages, not a claim that the app has identified the original song’s hook. New idea keeps the recorded pitch relationships between chops; the global Pitch setting still applies.

Set a value, then lock it

The row is called Random locks. First choose the value you want to preserve, then enable its lock. The highlighted lock state shows what the next draw must respect. Locks are kept with the project and recovery state.

LockWhat stays fixed
Hook patternThe selected repeated-letter structure and its number of chops.
SongThe selected source recording.
Playback BPMThe current playback tempo. When unlocked, a New idea follows the chosen source’s rounded BPM.
KeyThe selected estimated key. New idea looks for that key rather than transposing other passages into it.
LengthThe length of each source chop.
Editor lengthThe total workspace length.
↳
Length and Editor length are different

A one-bar chop repeated four times makes a four-bar workspace. Locking both values also constrains which hook patterns can fit. The current build has no Source BPM lock.

Vary the current response

Vary current keeps the opening motif and its repeats while looking for different responses or endings. It preserves the current timing and relevant settings. Use it when the basic idea works and you want a related version.

The current editor must be a full, compatible same-song hook: 4–32 equal, untrimmed indexed chops with no gaps or individual pitch shifts. If manual edits or lock combinations make the sequence ineligible, the status explains why and keeps the editor unchanged. Choose New idea or loosen a lock to continue.

↳
Portable audio and the search index

A portable project can reopen its saved audio without the original collection. Searching for new replacements or varying that hook still needs suitable passages in the indexed library.

Choose a hook shape deliberately

The Hook pattern selector includes Auto / vary pattern and named letter patterns. Repeated letters reuse the same chop. Selecting a pattern updates the progression preview; it does not silently replace the editor. Add or replace the progression, or make a New idea, to commit a new sequence.

If no hook fits, first try unlocking Hook pattern, Length or Editor length. A smaller collection or a song with few aligned passages naturally offers fewer combinations. Hooks & progressions →

Hooks & progressions

Build phrases from repeated sample motifs or use a harmonic progression as a guide.

Create a sequence from a passage

  1. Choose a starting passage

    Audition a passage, then open its context menu and choose Create sample hook or Create sample progression.

  2. Choose a Pattern

    Use an automatic hook, a named repeated-letter pattern or an available numeral progression. Preview the result before placing it.

  3. Commit the sequence

    Choose Add whole progression to editor to append it, or Replace editor with progression to use it as the new sample sequence.

The total length comes from the passage length multiplied by the number of steps. Choosing a longer editor does not automatically stretch a short progression to fill it.

Understand letters and chord numerals

PatternHow it behaves
Repeated lettersEach repeat uses the same source chop and its individual pitch setting. Different letters refer to different passages.
Explicit chord numeralsThe requested harmonic sequence can use matching passages or a same-mode pitch-matched fallback.
New ideaCreates a same-song hook that preserves recorded pitch relationships, with its own Random lock rules.

These are related workflows, but their harmonic matching is not identical. A literal progression may transpose a fallback passage; New idea does not use per-chop transposition to satisfy its Key lock.

Use the Library progression reference

Select a key in Library to enable the Progressions tab. It presents chord progressions for that key and lets you audition synthesized chord examples. Those examples are a harmonic reference; they are separate from the recorded passages in Samples.

↳
Check the harmony by ear

A passage’s estimated key does not describe every chord inside it. A matched label is a useful lead, not a guarantee of exact chord compatibility. Find a replacement passage →

Find a replacement

Audition another passage while preserving the place and role of the current one.

Open the replacement picker

Open a passage or editor clip’s context menu and choose Find key-matched replacement…. The picker looks within the same source recording and interpreted passage length, with a duration tolerance of about 10%. Direct estimated-key matches come first.

The optional pitch-matched fallback can offer same-mode passages that need transposition. Drum-phase alignment is available and enabled by default. Both the matching and alignment are estimates, so audition the result in context.

Preview, then commit

  1. Select a candidate

    Click a candidate row to preview it once. Hovering does not select or play it.

  2. Compare deliberately

    Arrow keys move the selection silently. Use Enter, Space or Preview to hear the selected candidate.

  3. Keep the replacement

    Choose Replace to commit. Escape or Cancel closes the picker and retains the existing sequence.

Preserve the phrase structure

Replacement keeps the clip’s position, musical length and target key. In Editor, Replace matching repeats can update repeated instances together. In a hook progression, repeats of the same hook letter are kept together.

↳
No suitable candidate?

Try disabling a matching restriction or choose a different passage. An imported project’s recovery audio is sufficient for playback, but the original indexed library may be needed to search for alternatives.

Program drums

Write a beat with eleven synthesized voices or generate a rhythm to edit.

Place hits on the grid

Open Drums. The eleven voices are kick, snare, low tom, mid tom, high tom, rim, clap, closed hat, open hat, crash and ride. Each bar has 16 steps. Click a step to cycle from off to a normal hit to an accented hit, then back to off.

Click a voice to audition it. Use its mute control to silence the row. Follow follows the active page during playback; turning it off lets you edit a different page while the pattern runs.

Generate a rhythm

Use Generate house, Generate boom-bap or Generate breaks for an editable starting point. The breaks controls include Vary breaks, Amen-style and Jungle. These build original rhythms using synthesized voices; they do not load a recording of a break.

Generation replaces the steps within the visible workspace length and can be undone. Shortening the workspace hides later bars without deleting them. Expand Bars again to recover the later pattern.

Set the feel and inclusion

Swing runs from 50% to 70% and affects the drums. Use a modest amount first, then listen against the sample’s existing rhythm. Closed and open hats choke each other, and drum tails stop at the workspace boundary.

Include drums controls their participation in workspace monitoring and editor audio export. Dedicated drum export has its own options. Change the kit and voice character in Drum sounds, then use Mixer for the final balance.

Shape the drum kit

Choose a kit and adjust each synthesized voice without rewriting the beat.

Open Kit sounds

Choose Kit sounds… in Drums, or right-click a voice to open its sound controls. The preset collection spans House / Club, Boom-bap and Jungle / Breaks. Selecting a kit changes the sounds while preserving the steps, mute states and swing.

The instruments use original 909-inspired synthesis. Treat the presets as starting points for your own sound, rather than exact hardware or recorded-break reproductions.

Shape a voice

ControlWhat it changes
LevelThe voice’s source level before its mixer channel.
TuneThe pitch of the synthesized drum.
ToneIts tonal balance or noise character.
DecayHow long the sound falls away.
Voice-specific controlsKick Attack, snare Snappy, clap Spread and ride Bell provide additional character.

Drag a knob for a broad change, hold Shift for a finer adjustment, or use the arrow keys when focused. The value input allows exact entry. Double-click resets the control. Sound changes are heard after the updated audio is ready.

Reset and balance independently

Reset voice returns that voice’s sound settings without clearing its steps. Save the project to keep kit choices and edits. The drum mixer faders are separate from voice Level, so you can change the final balance without redesigning the kit.

For separate audio files or a MIDI version of the pattern, use Export drums…. Drum export options →

Build synth parts

Create Bass, Lead, Poly and Pad parts that follow your samples or a chosen key.

Choose a track

Open Synths and choose Bass, Lead, Poly or Pad. Bass and Lead work with single-note parts; Poly and Pad work with grouped chords. Bass also offers the Two-oscillator bass and Acid 303 engines.

Use Track on to include a part in the workspace. Each track has its own Patch selection, note editor, local playback controls and Export track…. Local audition helps you inspect one part without changing its saved inclusion or mixer settings.

Choose the harmonic guide

Harmony modeHow generation is guided
Follow editor samplesFollows the sounding key estimates along the sample timeline, including sample transposition. Gaps or passages without a useful key do not generate new notes.
Manual keyUses the Key and major/minor Scale you choose.
↳
Generation does not transcribe the recording

The guide uses estimated key information rather than a complete chord analysis. Existing drawn or locked notes stay as they are until you edit or regenerate them.

Generate and constrain a part

Choose Generate [track] · play once for a new part and a single audition, or Generate all to build parts across the enabled tracks. The generated notes remain editable. Use the rhythm, notes and sound locks to keep the aspects you like.

ControlsUse them to
Allowed notesLimit a mono part to chord tones, scale tones, root only, root + fifth or a custom note set.
Root octave / Octave spanChoose the register and how widely a part can move.
Pattern bars / Step gridSet the generated phrase length and rhythmic spacing.
Density / note length / GateControl how busy and sustained the phrase becomes.
Accent / Slide / LeapsShape emphasis, connected movement and melodic jumps.
Generated chord / VoicingGuide Poly and Pad chord quality and use close, open or moving-inversion voicings.

Refine without losing the starting point

Generator setting changes reuse the current seed to make a related result while preserving the sound. Generate asks for a new variation. Selecting a patch locks the sound so later generation can keep it.

Use the note mask to see and adjust the allowed pitches: enabled notes are highlighted and the root is underlined. The Other notes controls expose the remaining chromatic choices. Edit the result in the piano roll or shape its sound and effects.

Edit notes & chords

Draw, move and reshape MIDI-style events inside each synth track.

Draw a note or a whole chord

In Select mode, double-click empty grid space to create an event. In Draw mode, click or drag in empty space. Press B while the roll is focused to switch modes. Double-click an existing event to erase it.

Bass and Lead create individual notes. Poly and Pad create chord groups: choose Chord type and Chord length, then place the root. Their supported chord lengths run from 1/32 to 8 bars. Moving a chord moves its tones together.

Move, resize and copy

Shift-click to select more events, or drag a selection marquee. Drag the selected group to move it; drag the right edge to resize. Delete or Backspace removes the selection. Arrow keys nudge selected events, and Shift with the up or down arrow moves them by an octave.

Copy and paste retain complete groups and their performance values. Click empty space to set a paste position; Duplicate appends a copy. If a destination collides with existing events, the edit is rejected as a whole. Poly and Pad can exchange chord groups; mono tracks do not accept chord groups.

⌘A selects the active roll’s events. Escape clears the selection. Click a piano key, note or chord to audition it; Stop ends the preview.

Separate editing snap from generation

The piano-roll Grid controls the editing snap, from 1/32 to 1/2. Changing it does not move notes already drawn. It is separate from the generator’s Step grid, which controls newly generated rhythms.

↳
Keep hidden work

Reducing the workspace length hides later events without deleting them. Expand Bars to reveal them again. Drag the roll’s lower edge to change its height; double-click that edge to return to the default height.

Synth sound & effects

Start from a patch, shape the instrument and add movement or space.

Shape the main instrument

Choose a track and a Patch, then refine its sound. The classic engine has two oscillators with waveform, semitone and fine tuning, plus blend, pulse, sub and noise controls. The filter offers low-pass, band-pass and high-pass modes with resonance and drive.

Separate amplitude and filter ADSR envelopes control the volume and filter movement over a note. Glide connects pitches. The LFO adds movement through its waveform, rate and pitch or filter depth. Make one change at a time and audition against the sample.

Use the Acid 303 engine

On Bass, set Engine to Acid 303 and choose an Acid patch. Its dedicated controls include Cutoff, Resonance, Env mod, Decay, Accent, Slide time, Drive, Tune and Level. Accent and connected-slide information in the notes affect how the phrase plays.

↳
Different envelope controls

The Acid engine uses its dedicated decay and envelope controls rather than the classic ADSR behavior. Its oscillator layering can change the tone further; audition the phrase after changing engines.

Add effects and compare

EffectCharacter
DistortionSoft clip, Overdrive, Fuzz, Metal, Diode, Foldback or Bit crush.
ChorusAdds width and movement.
EchoBeat-synced ping-pong repeats.
ReverbAdds a sense of space and a longer tail.

Use each effect’s bypass to compare the processed sound. Changes may need a new audio render, especially with longer patterns or more active voices. If the sound is still updating, let preparation finish before judging the change.

↳
Audio and MIDI serve different purposes

WAV preserves the rendered instrument and effects. MIDI carries notes and performance information for another instrument; it does not reproduce the SAMPLE-01 patch or effect chain.

Balance the mix

Control the sample bus, four synth parts, eleven drum voices and master output.

Find the channel you need

Open Mixer. Channels are grouped as Sample, Synths, Drums and Master. Scroll horizontally to reach more channels, or collapse a group to save space. Collapsing a group changes the view and does not silence it.

The Sample channel affects sample auditions, progressions and editor output consistently. Synth and drum channels let you balance the accompaniment. Voice sound Level and mixer level are separate stages.

Adjust levels, pan, mute and solo

Move a fader to change level and a pan control to place the channel in stereo. Mute silences a channel. Solo isolates channels; multiple solos can be active together, and a channel’s mute takes priority over its solo.

Double-click a fader to return to 0 dB or a pan control to return to center. Hold Shift for finer adjustment. Focused controls also respond to keyboard arrows. The meters show the rendered audio; click a clip indicator to clear it after correcting the level.

Check the master and export

Keep some headroom at Master, especially when several parts enter together. If the output clips, lower the contributing channels or master level and listen again. Live mixer changes affect playback and are included in audio export.

↳
Do not double the reference mix

Arrangement stems are aligned for import into a DAW. The ZIP also includes a reference mix: use it for comparison rather than playing it alongside all stems. MIDI is not an exact rendering of the mixer, instrument sound or effects.

Build an arrangement

Capture a short workspace and place its parts across a longer song timeline.

Turn a workspace into a pattern

  1. Finish a short idea

    Build a 1-, 2-, 4- or 8-bar workspace with samples, drums and synths.

  2. Name and add it

    Open Arrangement, enter an Idea name and choose Add workspace. This captures a reusable pattern and places its parts on the timeline.

  3. Place it again

    Choose the pattern in the pattern selector and use Place pattern for another linked placement. Use Make unique when the selected placement needs independent content.

The arrangement starts with 32 bars and can extend to 512. It has one playback tempo; captured patterns retain their own sample-pitch settings. Select Arrangement in the global playback source to hear the song.

Move, trim and repeat clips

Drag a clip’s body to move it and its edges to trim its range. The inspector provides position, length and source-offset controls. Enable Loop clips when an extended clip should repeat its source pattern. Snap choices range from 1/32 to 4 bars.

Shift-click or use a marquee to select multiple clips. Option-drag copies a clip; Copy, Paste and Duplicate support larger edits. Use ⌘E to split at the cursor and Delete to remove a selection. Undo is available for arrangement edits.

↳
Linked placements and independent copies

Place pattern reuses a pattern, so editing that pattern affects its linked placements. Copying creates an independent copy. Use Make unique before editing when a linked placement should become a separate variation.

Edit the pattern behind a clip

Double-click a clip or choose Edit pattern to open its source in the relevant workspace. The banner reads Live edits · all linked placements. Changes are prepared in the background and update the linked placements when the new audio is ready.

Choose Done editing to return to Arrangement. This current build uses live pattern editing, so you do not need a separate Update pattern step for every edit made in that mode. Make the pattern unique first if only one placement should change.

Navigate, loop and finish

Click the ruler to seek. Move or resize the loop brace to focus playback on a section. Section markers help you find parts of a longer song. Track groups can be collapsed and their mute/solo controls remain available.

Tempo and content changes can require background preparation. The current playback can continue while the updated audio is prepared, then switch at the current musical position. Save the project as you develop it and choose the export range when the arrangement is ready. Arrangement export →

Projects, saves & recovery

Keep an editable project, understand its audio references and make a portable copy.

Save a named project

File commandUse
New Project · ⌘NStart a new editable project.
Open Project… · ⌘OOpen a .sample01 project or a portable project ZIP.
Open RecentReturn to a recently opened project.
Save Project · ⌘SWrite the current changes to the named project.
Save Project As… · ⇧⌘SChoose a new name or location.

The window title indicates unsaved changes. A project keeps the editor, arrangement, synth and drum settings, mixer state and other editing choices. A normal .sample01 file refers to its audio rather than packaging the full original collection.

Keep the required audio with the project

Use File → Export → Portable Project ZIP… when moving a project or keeping an editable copy with its audio. The portable archive includes project data and recovery audio. Open the ZIP directly through Open Project; you do not need to extract it or rescan the original collection first.

↳
Playback is portable; browsing still needs a library

Imported recovery audio lets saved parts play without the original recordings. New idea, Vary current and replacement searches still rely on a suitable indexed collection. A normal project that references original files needs continued access to those files.

Distinguish recovery from Save

SAMPLE-01 keeps local recovery state as you edit. Recovery does not overwrite your named project file: use Save Project to commit the current state to that file. If you choose Discard when closing or changing projects, the app returns to the last saved project state, or a blank state for an unsaved project.

Use Help → Show Recovery Files to locate recovery data. Undo history is session-based and does not continue across reopening a project. Keep separate backups of work you want to preserve; recovery is not a versioned backup system.

Use saved editor snapshots

The saved-editor controls provide local snapshots with Save new, Update saved, Load and Delete saved. These are separate from the named project workflow. Deleting a saved snapshot moves that snapshot to its local trash; it does not clear the current editor or delete the source recordings.

File → Show Saved Arrangements opens the local saved-work location. For a copy that carries the wider editable project and audio, use the portable ZIP workflow above.

Export audio, MIDI & projects

Choose a rendered mix, separate parts or an editable archive for the next stage.

Export the short workspace

ExportWhat you receive
File → Export → Editor WAV…A rendered workspace mix using the current tempo, sample pitch, enabled instruments and mixer settings.
File → Export → Editor Samples…A ZIP containing the visible editor sample cells and a manifest; it does not add drum parts to each sample file.
Clip menu → Export sample WAVA WAV of the selected sample clip.
File → Export → Portable Project ZIP…An editable project archive with the audio required for recovery.

Workspace exports respect the current Bars boundary. Expand it before exporting if you need material that is currently hidden beyond the end.

Export drum and synth parts

Export drums…, also available through File → Export → Drum WAV / MIDI…, offers WAV with MIDI, WAV stems and MIDI patterns. Check Include muted voices if you want muted drum voices in that export. Dedicated voice exports let you keep individual parts separately from the workspace mix.

In Synths, use Export track… for the selected track’s WAV or MIDI, or use Selected Synth WAV… and Selected Synth MIDI… in the File export menu.

↳
Use WAV for the sound; MIDI for the performance

MIDI carries note and performance information and needs an instrument in the receiving app. It does not contain the SAMPLE-01 patch, processing or exact rendered mix.

Export an arrangement mix or ZIP

In Arrangement, choose Export arrangement WAV or the ZIP option. Enable Loop region only when you want just the marked range. When preparation finishes, use the generated save link to choose the destination.

Inside an arrangement ZIPPurpose
Reference_mix.wavA complete mix for listening and checking the imported parts.

Arrangement audio and stems are 24-bit, 44.1 kHz stereo. If a render exceeds 0 dBFS, export stops with a message to lower the Master or channel faders. The ZIP has a 2 GiB size limit; try a shorter export range if the complete song exceeds it.

Bring the parts into a DAW

  1. Match the tempo

    Set the receiving project to the arrangement’s tempo.

  2. Align the stems

    Place every stem at the same starting position and keep their shared duration. Disable automatic warping or time-stretching if it would alter the rendered timing.

  3. Compare with the reference

    Listen to the stems together, then compare against Reference_mix.wav. Keep the reference muted while playing the stems to avoid doubling the audio.

  4. Assign instruments to MIDI

    Load a suitable instrument for each MIDI part and choose its sound. Use the WAV version when you need the exact rendered SAMPLE-01 sound.

Use controls precisely

Tab and Shift-Tab move focus through controls. Focused knobs and faders respond to arrow keys; hold Shift for a fine adjustment where supported. Double-click a mixer fader to reset it to 0 dB or pan to center. Drum sound knobs also provide exact value entry and double-click reset.

Text fields keep their normal text-editing behavior. Shortcuts act on the active workspace, so select the relevant editor first. Open Help → Keyboard Shortcuts for the in-app reference.

Troubleshooting

Resolve common library, playback, generation and save problems.

Missing files or too few passages

SymptomCheck
No songs appearChoose the SAMPLE folder, run a scan and Refresh library. Clear song search and restrictive filters.
A file was skippedOpen Skipped files. Check its format, duration and whether the file can be read. Supported sources are FLAC, MP3 and WAV, up to 20 minutes.
A saved clip cannot find audioRestore access to its original folder. A normal .sample01 file may still refer to that collection; a portable ZIP can carry recovery audio.
Few or no passages fitTry All lengths, All BPM and All keys. Sparse percussion, irregular timing and uncertain analysis can limit the suggestions.
The musical length feels wrongSelect the song and compare Detected, Half tempo and Double tempo under Beat grid.

Silence or delayed playback

Check the selected playback source first: Workspace and Arrangement contain different material. Then check that the part has events, its inclusion or Track on control is enabled, and its mixer channel is not muted or excluded by another solo. Inspect channel and master levels, then the Mac’s selected audio output.

New tempo, pitch, sound or arrangement settings can require audio preparation. Indexing shares processing resources, so audition preparation may wait for the current recording to finish. Let the current task complete before trying again.

↳
A local audition is a useful check

Preview one sample, drum voice or synth track. If that works, inspect workspace inclusion and mixer routing. If nothing plays, check the output device and master level.

A New idea or variation cannot be built

Read the status message, then try loosening Hook pattern, Length or Editor length. Those locks must describe a compatible total. A locked song or key can leave too few aligned passages for a fresh result. An unsuccessful draw keeps the current editor intact.

Vary current needs an eligible full same-song hook of equal untrimmed indexed chops. Gaps, manual trims, individual pitch changes or missing library references can prevent variation. Use New idea to start another eligible sequence.

Save, recovery and export problems

If Save fails, check access to the destination and available disk space, then try Save Project As… in a writable location. Recovery autosave does not update the named project file. Use Help → Show Recovery Files to inspect local recovery data.

For a large arrangement ZIP, export a shorter loop region to stay within the archive limit. If an exported MIDI file is silent elsewhere, assign an instrument to it; MIDI itself contains no audio. Export reference →

A guide to using the app

SAMPLE-01 helps turn a collection of recordings into playable passages and editable musical ideas. Indexing and auditioning a large collection in one place reduces the repeated work of dropping individual tracks into a DAW. The same tools are useful with a small, focused collection.

This site is documentation. Its chapters explain the app’s controls, local file workflow and export formats. Keyboard shortcuts and File-menu instructions refer to the native macOS app.
